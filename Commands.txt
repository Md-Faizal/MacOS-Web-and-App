🚨 TROUBLESHOOTING
================================================================================

ERROR 522 (Cloudflare can't reach origin):
  Windows: Check pm2 status - frontend must bind to :: (IPv6)
           pm2 restart frontend && pm2 logs frontend
  Ubuntu:  Check nginx + pm2 status on VM
           ssh my-mac 'pm2 status && sudo systemctl status nginx'

Nginx "conflicting server name" warning:
  ssh my-mac 'ls /etc/nginx/sites-enabled/'
  ssh my-mac 'sudo rm /etc/nginx/sites-enabled/<OLD-CONFIG>'
  ssh my-mac 'sudo nginx -t && sudo systemctl reload nginx'

Assets 404 on Ubuntu (JS/CSS not loading):
  1. Check if assets exist: ssh my-mac 'ls /home/ubuntu/MacOS-Production/assets/'
  2. If missing, re-sync: scp -r dist/assets my-mac:/home/ubuntu/MacOS-Production/
  3. Hard refresh browser: Ctrl+Shift+R

CSS MIME type error ('text/html' instead of 'text/css'):
  Nginx served wrong file. Check nginx config is active:
  ssh my-mac 'sudo nginx -t && sudo systemctl reload nginx'

PM2 "Environment [production] is not defined":
  Always use --env flag: pm2 start ecosystem.config.js --env production --update-env
  (env blocks must be named env_production / env_oraclevm in ecosystem.config.js)

Port 80 EACCES on Ubuntu (permission denied):
  sudo setcap 'cap_net_bind_service=+ep' $(which node)

Services crash loop on Ubuntu:
  ssh my-mac 'pm2 logs --lines 100'
  (check for missing files or database errors)

👤 USER MANAGEMENT (API - use after server is running)
────────────────────────────────────────────────────────────────────────────────

  Note: Replace <TOKEN> with owner's auth_token cookie value for curl commands.
  Easier to use the Admin Panel UI at https://mac.faizal.uk/#admin

LIST ALL USERS:
  curl -b "auth_token=<TOKEN>" https://mac.faizal.uk/api/admin/users

GET USER DETAILS + PERMISSIONS:
  curl -b "auth_token=<TOKEN>" https://mac.faizal.uk/api/admin/users/<USER_ID>

APPROVE A PENDING WORKER (with their invite code):
  curl -X POST -b "auth_token=<TOKEN>" \
    -H "Content-Type: application/json" \
    -d '{"inviteCode":"ABC123"}' \
    https://mac.faizal.uk/api/admin/users/<USER_ID>/approve

SUSPEND A WORKER (immediately invalidates their session):
  curl -X POST -b "auth_token=<TOKEN>" \
    https://mac.faizal.uk/api/admin/users/<USER_ID>/suspend

SET MODULE PERMISSIONS FOR A WORKER:
  curl -X PUT -b "auth_token=<TOKEN>" \
    -H "Content-Type: application/json" \
    -d '{"billing":{"can_view":1,"can_create":1,"can_edit":1,"can_delete":0},"contacts":{"can_view":1,"can_create":0,"can_edit":0,"can_delete":0}}' \
    https://mac.faizal.uk/api/admin/users/<USER_ID>/permissions

SET ALLOWED CONTACTS FOR A WORKER (by contact IDs):
  curl -X PUT -b "auth_token=<TOKEN>" \
    -H "Content-Type: application/json" \
    -d '{"contactIds":[1,5,12,34]}' \
    https://mac.faizal.uk/api/admin/users/<USER_ID>/contacts

ASSIGN APK UPDATE CHANNEL FOR A WORKER:
  curl -X PUT -b "auth_token=<TOKEN>" \
    -H "Content-Type: application/json" \
    -d '{"channel":"testing"}' \
    https://mac.faizal.uk/api/admin/users/<USER_ID>/channel

GET OWNER NOTIFICATIONS (pending approvals etc):
  curl -b "auth_token=<TOKEN>" https://mac.faizal.uk/api/admin/notifications

📦 GIT VERSION CONTROL & REPOSITORY MANAGEMENT
================================================================================

DAILY WORKFLOW (SAVE YOUR PROGRESS):
  1. Check what files you changed:
     git status

  2. See exact line-by-line code changes:
     git diff

  3. Save a checkpoint (Commit):
     git add .
     git commit -m "Describe what changes you made"

  4. View version history (Timeline):
     git log --oneline
     git log -n 5 --graph --oneline

PANIC BUTTONS & UNDOING MISTAKES:
  - Discard all uncommitted edits (revert back to last save point):
    git restore .

  - Unstage files you added by mistake before committing:
    git restore --staged <file>

  - Go back to a specific previous commit:
    git checkout <commit-hash>
    (To return back to latest: git checkout master)

BRANCHING (SAFE TESTING & EXPERIMENTATION):
  1. Create and switch to an experiment branch:
     git checkout -b test-new-feature

  2. Work, edit, and test freely. If you love it, merge into master:
     git checkout master
     git merge test-new-feature

  3. If you hate it, simply delete the branch without touching master:
     git checkout master
     git branch -D test-new-feature

CLEANING UNTRACKED FILES / STATUS:
  - Check ignored vs tracked files:
    git status --ignored
