❓ Troubleshooting

Data not showing in app?
Try reloading the page and checking browser console (F12) for errors
Want to clear and start fresh?
Click "Clear All Data" and then reseed
Backend API not working?
Make sure the Node.js server is running: npm run dev
Database file missing?
Run: node database/seed-data-fixed.js from project root
