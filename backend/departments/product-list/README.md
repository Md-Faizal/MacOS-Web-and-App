# Product List Department

This department owns the catalog and assortment model.

## Responsibilities
- Product master records
- Variants and pricing metadata
- Batch records
- Category organization
- Catalog search and public listing responses

## Service Boundary

The `service.js` façade standardizes the catalog response envelope while preserving legacy route behavior.

## Contract

Canonical API contract lives in `../../shared/api/product-list-contract.js`.
